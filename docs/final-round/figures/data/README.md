Each chart script under `diagrams/` (or `figures/`) reads exactly one `figures/data/FNN.json` file as its data source, keeping every chart's numbers traceable to a single JSON record rather than hard-coded literals in plotting code. Placeholder values — the same ones flagged with `\abl{}` in `data/numbers.tex` — carry an `"abl": true` field in their JSON so scripts and reviewers can tell measured numbers apart from ablation-pending stand-ins at a glance; once the board ablation run completes, those fields are overwritten with real measurements and `"abl"` is flipped to `false`.
