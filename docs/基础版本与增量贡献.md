# 基础版本与增量贡献

本文件按 2026 技术方案 §1.1 的要求，清楚标注本工作所基于的基础版本，并列出本队在其上的增量贡献及其上游提交状态。基础版本在仓库首次提交中即予标注。

## 三、贡献与基础版本的边界

性能优化分两类，本工作在结果中始终区分。其一是用户侧的优化，例如大核放置、整数输出路径、与相机一致的输入尺寸与 RGA 解码，这些在 Linux 上同样适用，作用是把 StarryOS 与 Linux 的差距收敛到同一水平；其二是对 StarryOS 本身的内核侧贡献，例如上表中的各项驱动、系统调用、负载均衡器与块设备修复，这些是本工作对该研究型操作系统的增量。两类在报告与文档中分别呈现，不相混淆。
